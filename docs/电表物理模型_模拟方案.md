# 虚拟电表物理模型 - 基于电气关系的模拟方案

## 一、电表数据的物理关系

### 1.1 核心物理量

```
基础物理量 (Primary)           推导物理量 (Derived)
├─ 电压 U (V)          ────→   ├─ 瞬时功率 P (kW)
├─ 电流 I (A)          ────→   ├─ 功率因数 cosφ
└─ 相位角 φ (°)        ────→   ├─ 无功功率 Q (kvar)
                              ├─ 视在功率 S (kVA)
                              └─ 电能量 E (kWh)
```

### 1.2 基本公式

```
三相电路:
├─ 有功功率:   P = √3 × U × I × cosφ  (kW)
├─ 无功功率:   Q = √3 × U × I × sinφ  (kvar)
├─ 视在功率:   S = √3 × U × I         (kVA)
├─ 功率因数:   PF = P / S = cosφ
└─ 电能累积:   E(t) = ∫ P(t) dt

单相:
├─ 有功功率:   P = U × I × cosφ
├─ 无功功率:   Q = U × I × sinφ
└─ 视在功率:   S = U × I

关系:
├─ S² = P² + Q²  (功率三角形)
└─ E = P × t     (简化: 假设功率恒定)
```

## 二、物理模型设计

### 2.1 核心思想

```
只需要模拟 3 个基础物理量:
1. 电压 U(t)  - 波动曲线
2. 电流 I(t)  - 负载曲线
3. 功率因数 cosφ(t) - 缓慢变化

其他所有量都通过计算得出!
```

## 三、核心实现架构

### 3.1 物理引擎 (Physics Engine)

```rust
/// 物理模拟引擎 - 核心
pub struct PhysicsEngine {
    /// 系统时间 (模拟时钟)
    sim_time: SimTime,
    
    /// 基础物理量
    voltage: ThreePhaseVoltage,
    current: ThreePhaseCurrent,
    power_factor: PowerFactor,
    
    /// 能量积分器
    energy_integrator: EnergyIntegrator,
    
    /// 统计追踪器
    statistics_tracker: StatisticsTracker,
}

impl PhysicsEngine {
    /// 推进时间 (核心方法)
    pub fn advance_time(&mut self, delta: Duration) {
        self.sim_time.advance(delta);
        
        // 1. 更新基础物理量
        self.voltage.update(self.sim_time);
        self.current.update(self.sim_time);
        self.power_factor.update(self.sim_time);
        
        // 2. 计算瞬时功率
        let powers = self.calculate_powers();
        
        // 3. 积分计算电能
        self.energy_integrator.integrate(powers, delta);
        
        // 4. 更新统计数据
        self.statistics_tracker.update(powers, self.sim_time);
    }
    
    /// 计算瞬时功率
    fn calculate_powers(&self) -> ThreePhasePower {
        let pa = self.voltage.phase_a * self.current.phase_a * self.power_factor.value / 1000.0;
        let pb = self.voltage.phase_b * self.current.phase_b * self.power_factor.value / 1000.0;
        let pc = self.voltage.phase_c * self.current.phase_c * self.power_factor.value / 1000.0;
        
        ThreePhasePower {
            phase_a: pa,
            phase_b: pb,
            phase_c: pc,
            total: pa + pb + pc,
        }
    }
    
    /// 查询数据项
    pub fn query(&mut self, di: [u8; 4]) -> Result<Vec<u8>> {
        // 确保时间推进 (如果距离上次查询已过时间)
        let now = Instant::now();
        let elapsed = now - self.last_query_time;
        if elapsed > Duration::from_millis(100) {
            self.advance_time(elapsed);
        }
        self.last_query_time = now;
        
        // 根据 DI 查询对应数据
        match di {
            // 瞬时电压
            [0x02, 0x01, 0x01, 0x00] => {
                Ok(encode_bcd(self.voltage.phase_a, 2, 1))
            },
            // 瞬时电流
            [0x02, 0x02, 0x01, 0x00] => {
                Ok(encode_bcd(self.current.phase_a, 3, 3))
            },
            // 瞬时有功功率
            [0x02, 0x03, 0x01, 0x00] => {
                let power = self.calculate_powers().phase_a;
                Ok(encode_bcd(power, 3, 4))
            },
            // 当前正向有功总电能
            [0x00, 0x01, 0x00, 0x00] => {
                let energy = self.energy_integrator.total_forward_active;
                Ok(encode_bcd(energy, 4, 2))
            },
            // ... 其他 DI
            _ => Err(Error::UnknownDI(di)),
        }
    }
}
```

```rust
/// 负载曲线 (24小时用电模式)
pub struct LoadCurve {
    profile_type: LoadProfile,
    base_load: f64,
    peak_load: f64,
    time_pattern: Vec<TimeSegment>,
}

#[derive(Clone, Copy)]
pub enum LoadProfile {
    Residential,   // 居民用电
    Industrial,    // 工业用电
    Commercial,    // 商业用电
}

pub struct TimeSegment {
    start_hour: u8,
    end_hour: u8,
    load_factor: f64,  // 0.0 - 1.0
}

impl LoadCurve {
    /// 获取当前时刻的电流值
    pub fn get_current(&self, sim_time: &SimTime) -> f64 {
        let hour = sim_time.hour();
        
        // 找到当前时段
        let factor = self.time_pattern.iter()
            .find(|seg| hour >= seg.start_hour && hour < seg.end_hour)
            .map(|seg| seg.load_factor)
            .unwrap_or(0.5);
        
        // 基础负载 + (峰值负载 - 基础负载) × 时段系数 + 随机波动
        let base = self.base_load;
        let range = self.peak_load - self.base_load;
        let noise = rand::thread_rng().gen_range(-0.05..0.05);
        
        base + range * factor * (1.0 + noise)
    }
    
    /// 预定义居民用电模式
    pub fn residential() -> Self {
        Self {
            profile_type: LoadProfile::Residential,
            base_load: 5.0,
            peak_load: 40.0,
            time_pattern: vec![
                TimeSegment { start_hour: 0,  end_hour: 6,  load_factor: 0.2 },  // 深夜
                TimeSegment { start_hour: 6,  end_hour: 9,  load_factor: 0.7 },  // 早高峰
                TimeSegment { start_hour: 9,  end_hour: 17, load_factor: 0.4 },  // 白天
                TimeSegment { start_hour: 17, end_hour: 22, load_factor: 1.0 },  // 晚高峰
                TimeSegment { start_hour: 22, end_hour: 24, load_factor: 0.3 },  // 夜间
            ],
        }
    }
}
```

### 3.3 能量积分器

```rust
/// 能量积分器 (核心: 电能 = ∫功率 dt)
pub struct EnergyIntegrator {
    /// 总电能
    pub total_forward_active: f64,   // 正向有功总
    pub total_reverse_active: f64,   // 反向有功总
    pub total_reactive_1: f64,       // 组合无功1
    
    /// 分时电能
    pub rate_energies: [f64; 4],     // 费率1-4电能
    
    /// 当前费率
    current_rate: u8,
    
    /// 上次积分时间
    last_integration_time: SimTime,
}

impl EnergyIntegrator {
    /// 积分计算 (梯形法)
    pub fn integrate(&mut self, power: ThreePhasePower, delta: Duration) {
        let dt_hours = delta.as_secs_f64() / 3600.0;  // 转换为小时
        
        // 总有功电能增量 = 功率 × 时间
        let delta_energy = power.total * dt_hours;
        
        if power.total >= 0.0 {
            // 正向
            self.total_forward_active += delta_energy;
            
            // 分时累积
            let rate_idx = self.get_current_rate();
            self.rate_energies[rate_idx as usize] += delta_energy;
        } else {
            // 反向 (光伏发电等)
            self.total_reverse_active += delta_energy.abs();
        }
        
        self.last_integration_time.advance(delta);
    }
    
    /// 获取当前费率 (根据时间)
    fn get_current_rate(&self) -> u8 {
        let hour = self.last_integration_time.hour();
        
        match hour {
            8..=11 | 18..=23 => 1,   // 尖时段
            12..=17 => 2,             // 峰时段
            6..=7 => 3,               // 平时段
            _ => 4,                   // 谷时段
        }
    }
}
```

### 3.4 统计追踪器

```rust
/// 统计追踪器 (最大需量等)
pub struct StatisticsTracker {
    /// 15分钟滑动窗口
    sliding_window: VecDeque<PowerSample>,
    window_size: Duration,
    
    /// 当前最大需量
    max_demand: f64,
    max_demand_time: SimTime,
}

pub struct PowerSample {
    timestamp: SimTime,
    power: f64,
}

impl StatisticsTracker {
    /// 更新统计数据
    pub fn update(&mut self, power: ThreePhasePower, sim_time: SimTime) {
        // 添加新样本
        self.sliding_window.push_back(PowerSample {
            timestamp: sim_time,
            power: power.total,
        });
        
        // 移除过期样本 (超过15分钟)
        while let Some(sample) = self.sliding_window.front() {
            if sim_time - sample.timestamp > self.window_size {
                self.sliding_window.pop_front();
            } else {
                break;
            }
        }
        
        // 计算15分钟平均功率
        if !self.sliding_window.is_empty() {
            let avg_power: f64 = self.sliding_window.iter()
                .map(|s| s.power)
                .sum::<f64>() / self.sliding_window.len() as f64;
            
            // 更新最大需量
            if avg_power > self.max_demand {
                self.max_demand = avg_power;
                self.max_demand_time = sim_time;
            }
        }
    }
}
```

## 五、优势分析

### 5.1 物理模型方案 vs 独立模拟方案

| 特性 | 物理模型方案 ✅ | 独立模拟方案 ❌ |
|------|-----------------|-----------------|
| 数据一致性 | 完美 (物理公式保证) | 差 (需要手动约束) |
| 配置复杂度 | 低 (只配3个基础量) | 高 (配2500+项) |
| 真实性 | 高 (符合物理规律) | 低 (随机波动) |
| 维护成本 | 低 | 高 |
| 扩展性 | 高 (自动计算派生量) | 低 (每个DI都要配) |

### 5.2 示例对比

**物理模型方案**:
```yaml
# 只需配置
voltage: 220V
current: 10-50A (负载曲线)
power_factor: 0.95

# 自动得到
power = U × I × cosφ = 220 × 30 × 0.95 = 6.27 kW
energy += power × Δt
max_demand = max(avg(power, 15min))
```

**独立模拟方案** (❌不推荐):
```yaml
# 需要分别配置
voltage: { mode: wave, center: 220, ... }
current: { mode: wave, center: 30, ... }
power: { mode: wave, center: 6.27, ... }  # 可能不一致!
energy: { mode: accumulative, rate: 0.1, ... }  # 可能不匹配!
```
